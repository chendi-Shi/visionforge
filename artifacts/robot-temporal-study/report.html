解释边界

  • 8 tasks, one success and one failure each: natural class prevalence is changed.
  • Some author reason text was encountered during source research; selection used stable hashes and class strata, not onset, failure type, reason or observed model scores.
  • Offline full-recording diagnosis and one overview camera; no online latency, training or control claims.
  • Both models use the same frozen prompt, 12-frame budget, exact panel bytes and sampler selections.
  • Model identity differs; this is not an isolated parameter-count, architecture or training-data experiment.
  • No tuning, inference or new selection is performed by this comparison.
  • Task-cluster intervals are descriptive on this small stratified subset. Missing/failed outputs remain abstentions in all paired denominators.
  • Ground-truth onsets are author annotations; displayed visual evidence and annotated failure onset can differ.
